## v1.21.2

### 主要版本信息

完善存储迁移、一次性定时任务与 LLM 失败续跑，补齐浏览器导出和内置 uv 安装能力，并修复暗色模式及旧版目录迁移问题。

### 更新内容

#### 功能与体验

- Windows 安装器支持选择安装目录；“设置 → 运行环境 / 输出与文件”提供存储迁移入口，包含空间预览、文件校验、数据库与 JSON 路径更新、新位置启动验证和失败恢复。
- 首页右侧菜单提供一次性“定时设置【时间】｜开始”，支持分 P 与合集批量；普通“开始总结”立即执行，未来任务不会阻挡即时任务。
- LLM 失败后保留转写与分段，修正配置后可仅重跑 LLM，沿用同一个任务；重启服务后仍可恢复。
- 首页支持进入自定义摘要提示词预设编辑，保存后可选择使用。
- Web / Docker 界面支持直接下载 Markdown / Obsidian，含图片时导出 ZIP。
- 桌面包内置 uv，依赖安装使用指定运行时与缓存，必要时回退 pip。
- 完善合集设置、视频右键菜单与批量操作。

#### 修复

- 支持旧版数据目录下嵌套缓存、任务和导出目录，避免重复统计与复制；未选目录及其引用保留在原位置。
- 排除应用创建的安装临时目录，修复 pip 临时目录 EPERM 阻塞迁移；模型缓存和任务数据继续严格检查。
- 修复迁移卡片长路径溢出、错误信息堆叠，以及迁移停机时设置页和进度消失。
- 改善 OpenAI 兼容网关 JSON / SSE / 流结束标记处理，保留 Gemini 和 NDJSON 兼容；鉴权错误不自动重试，限流与暂时性错误有限重试。
- 修复暗色模式自定义提示词按钮、更新提示及版本信息行样式。
- 修复 Windows 无控制台启动异常与首次安装托管 Python 初始化问题。

### 使用说明

- 定时执行需要应用或服务保持运行；休眠和关机期间不会唤醒系统。
- 迁移验证通过前保留旧文件；未迁移、已变化或无法校验的旧文件不会被直接清理。
- 本地已完成独立测试目录的真实后端 EXE 迁移、数据库 / JSON 路径更新及注入启动失败后的恢复测试；未搬动用户生产数据或重装现有 GPU 环境。
