## Design Context

### Users

BiliSum desktop users who paste Bilibili, YouTube, or local video URLs and want to understand videos locally. Collection users need a quick overview before choosing single-video or batch processing.

### Brand Personality

Calm, focused, and trustworthy. Copy is concise and action-oriented. The visual tone is dark, editorial, and utilitarian with the existing warm pink accent.

### Aesthetic Direction

Keep the existing BiliSum dark desktop utility language: tinted graphite surfaces, restrained borders, and warm pink emphasis. Collection UI should feel like a compact file tree/folder rather than a large modal or generic card grid. Use progressive disclosure, subtle 150–220ms transitions, responsive behavior, and reduced-motion support.

### Design Principles

1. Probe results should answer “what did we find?” before asking for an action.
2. Treat a collection as a parent container with independently visible child videos.
3. Keep the primary action singular: summarize the selected content.
4. Preserve existing single-video and multi-P behavior.
5. Make collapsed/expanded state keyboard accessible and visually obvious.
