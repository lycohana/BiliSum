# v1.21.2 更新说明

本次更新完善存储迁移、一次性定时任务和失败续跑，并修复接口兼容及暗色模式显示问题。

## 重点更新

- **存储位置迁移**：Windows 安装器支持选择安装目录；在“设置 → 运行环境”或“输出与文件”中，可迁移应用数据和托管运行时。迁移前展示空间预览，复制后逐文件校验，更新数据库与 JSON 路径，通过新位置启动验证后再决定是否清理旧副本。迁移失败会尝试恢复旧位置并重新启动服务。
- **适配旧版数据目录**：支持数据目录内嵌套缓存和任务目录，不重复复制或统计空间；未选择的外置导出目录留在原位置。安装临时文件不参与迁移，模型缓存和任务数据仍严格检查。
- **一次性定时处理**：打开首页“开始总结”右侧菜单，在“定时设置”中选好本地时间并点击该行“开始”，仅本次任务使用该时间；外侧“开始总结”仍立即执行。分 P 和合集批量任务沿用本次选择。执行时应用或服务需要保持运行，关机或休眠期间不会唤醒系统。
- **复用转写继续生成**：LLM 失败后保留转写和分段，可在详情页选择“仅重跑 LLM（复用转写）”。修正 Key 或模型设置后继续同一个任务，服务重启后也可恢复。
- **自定义摘要提示词**：从首页生成偏好的“摘要 Prompt”进入“自定义提示词 / 新建预设”，保存后即可手动选择使用。
- **浏览器导出**：Web / Docker 界面可直接下载 Markdown / Obsidian 笔记，带图片时下载包含图片的 ZIP。
- **内置 uv**：桌面包携带 uv，依赖安装优先使用内置安装器和已配置的缓存，必要时回退 pip。

## 修复与体验改进

- 改善 OpenAI 兼容网关的 JSON、SSE 和流结束标记处理，保留已有 Gemini 与 NDJSON 兼容；鉴权失败不反复重试，限流和暂时性服务错误采用有限重试。
- 修复迁移预览扫描安装临时目录时被权限错误阻塞、嵌套目录误判冲突、长路径撑出卡片和迁移停机时设置页丢失的问题。
- 修复暗色模式下自定义提示词按钮、“有新版本”提示和版本信息行的颜色与对比度。
- 完善合集设置、视频右键菜单及批量操作的一致性。
- 修复首次启动托管 Python 初始化及 Windows 无控制台后端启动问题。

# v1.21.0 更新说明

本次版本重点完善 B 站视频合集工作流，同时优化 LLM 请求缓存、任务并发和队列反馈，让批量总结更快、更稳定，也更容易掌握当前任务进度。

## ✨ 重点更新

- **B 站合集完整工作流**：从带合集的视频开始总结时，BiliSum 会自动识别所属合集，并将合集作为视频库中的独立卡片展示；合集内视频默认收纳在详情页中，不再直接挤占外层视频库，合集卡片与普通视频卡片共享封面、尺寸、排序、收藏、分组和右键菜单逻辑。合集详情页使用和视频库一致的卡片网格/列表视图，默认优先展示已总结内容，排队中和处理中的视频也会保留在已总结分组并显示当前状态；支持返回合集、查看并打开 UP 主空间、按照集数和总结状态管理视频、进入选择模式后多选或连续拖动选择、全选未总结内容和一键总结已选视频。打开合集时可以自动检查远端新视频并通过弱提示询问是否加入，视频可以在保留合集归属的同时提升到外层视频库；同时支持刷新列表、收藏、置顶、设置分组，以及选择只移除合集文件夹或连同视频、任务和摘要一起删除。合集批量总结在第一个任务创建成功后立即进入合集页，后续视频在后台继续读取参数和创建任务，视频探测会受到转写并发设置限制。
- **任务队列与并发反馈**：标题栏新增当前队列状态，展示已完成/总任务、目前运行和剩余队列；展开后可以查看并发任务、非并发任务、进度百分比、运行时间和 Token 消耗。任务完成后会以短暂的完成状态平滑收起，不影响继续使用软件。
- **LLM 缓存优化**：优化摘要上下文和提示词缓存的复用与统计，减少重复上下文带来的额外请求和 Token 消耗；任务详情和队列信息会区分缓存命中、缓存未命中以及本次请求消耗，方便评估实际成本。
- **分阶段并发控制**：转写、LLM、摘要分块和思维导图使用独立的并发配置，队列会按照对应阶段调度任务，避免某一阶段的并发数量挤占其他阶段的资源。

## 💡 使用建议

- **想要更快、更省 Token**：如果当前任务不需要模型展示思考过程，可以在设置中关闭 **思考链**。关闭后模型会减少额外的推理输出，通常可以缩短等待时间并降低 Token 消耗；需要复杂分析时可以保持开启。
- **合理设置并发数**：网络和 API 服务允许时可以适当提高 LLM 并发数；如果遇到限流、超时或本地资源紧张，建议降低转写或 LLM 并发数。合集任务会遵循这些配置，不会无上限地同时请求。
- **关注缓存统计**：对于相似提示词或重复上下文，缓存命中率越高，重复计算和输入 Token 成本通常越低；不同模型服务商对提示词缓存的支持和计费方式可能不同，请以服务商实际返回的用量为准。
- **批量处理合集**：进入合集详情页后优先使用“全选未总结”或拖动连续选择，再通过底部操作栏一键创建任务；任务会在后台继续运行，可以直接查看合集内状态变化。

## 🐛 修复与稳定性改进

- 修复合集批量读取参数过慢、内部错误提示不明确、从合集内打开视频后返回路径错误，以及合集卡片、普通视频卡片和拖拽预览之间拖动把手显示不一致的问题；同时增加更明确的错误提示和重试处理。
- 修复失败任务进度条没有归零、完成任务没有显示 100% 的问题；失败显示红色 0%，完成显示绿色 100%。
- 修复 LLM 设置保存后刷新恢复旧值的问题，保存并关闭后会以服务端持久化配置为准。
- 修复全局通知条出入动画、自动消失时间和多窗口遮挡问题，默认保留 5 秒并使用一致的主题样式。

# v1.20.0 更新说明
